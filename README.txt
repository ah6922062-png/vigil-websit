VIGIL — الموقع الثابت
======================

الملفات:
- index.html: الصفحة الرئيسية والخدمات والنماذج التفاعلية.
- styles.css: التصميم المتجاوب والهوية الفضائية.
- app.js: بيانات الخدمات والتحقق من النماذج والنسخ وفتح واتساب.
- privacy.html: سياسة الخصوصية.

تشغيل محلي:
افتح index.html في متصفح حديث. يفضّل استخدام خادم محلي بسيط عند الاختبار، لكن لا توجد عملية بناء أو تثبيت مطلوبة.

النشر المجاني:
1. فك ضغط ZIP.
2. أنشئ مستودعًا جديدًا في GitHub وارفع الملفات الأربعة إلى الجذر.
3. من Settings > Pages اختر Deploy from a branch، ثم الفرع main والمجلد /(root)، واحفظ.
4. انتظر انتهاء النشر، ثم افتح الرابط الذي يظهر في GitHub Pages.

مهم:
- لم يتم نشر الموقع على الإنترنت من هذه الملفات وحدها، ولا يوجد رابط عام حتى تنشره.
- لا توجد قاعدة بيانات أو لوحة تحكم أو نظام متابعة؛ أرقام الطلبات محلية فقط.
- نموذج واتساب يفتح رسالة جاهزة بعد موافقة المستخدم، ولا يرسلها تلقائيًا.
- Google Fonts يتطلب اتصالًا بالإنترنت، ويستخدم الموقع خطوطًا احتياطية عند عدم توفره.
